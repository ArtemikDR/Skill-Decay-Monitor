Skill Decay Monitor
Данный проект является аналитической платформой для оценки актуальности технических навыков на рынке труда в сфере искусственного интеллекта и анализа данных. Разработчик: grande inkvisitor.

Загрузка и обработка данных

Система загружает датасет, содержащий более 72000 записей о вакансиях и зарплатах за период с 2020 по 2026 год. Данные автоматически очищаются от пропусков и аномалий, а зарплаты нормализуются к единой валюте для корректного сравнения.

Извлечение навыков

С помощью регулярных выражений алгоритм автоматически извлекает технические навыки (например, Python, TensorFlow, AWS, SQL) из названий должностей и текстовых категорий вакансий.

Расчет метрик

Для каждого выявленного навыка вычисляются ключевые показатели: темп роста медианной зарплаты, изменение количества вакансий и комплексный индекс устаревания, который объединяет эти факторы в одну итоговую оценку.

Классификация и визуализация

Навыки автоматически распределяются по четырем категориям: растущие, стабильные, угасающие и устаревшие. Результаты выводятся в интерактивный веб-дашборд, где пользователь может фильтровать данные, просматривать графики динамики зарплат и детальные таблицы рейтингов.

Используемые технологии

Программирование: Python — основной язык программирования. Pandas и NumPy — библиотеки для обработки и анализа табличных данных.
Обработка текста: Регулярные выражения (Regex) для парсинга и классификации навыков.
Визуализация и интерфейс: Streamlit — фреймворк для создания веб-дашборда. Plotly — библиотека для построения интерактивных графиков.
Хранение данных: Формат CSV для исходного датасета и файлов с результатами анализа.
Разработка и тестирование: PyCharm или VS Code — среды разработки. Git и GitHub — для контроля версий и хранения кода. Ручное тестирование пайплайна обработки данных для поиска логических ошибок.
