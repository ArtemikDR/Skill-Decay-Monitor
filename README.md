Skill Decay Monitor
Данный проект является аналитической платформой для оценки актуальности технических навыков на рынке труда в сфере искусственного интеллекта и анализа данных. Разработчик: Оуджи буда.

Загрузка и обработка данных

Историческая часть использует 71 913 записей зарплатного опроса из разных стран за 2020–2025 годы. Источник — AI Impact on Jobs & Salaries на Kaggle: https://www.kaggle.com/datasets/debayank2024/ai-impact-on-jobs-and-salaries-2020-2026. Зарплаты в исходном поле salary_in_usd уже представлены в долларах США. При загрузке зарплата и год преобразуются в числовой формат, записи без числовой зарплаты исключаются. Флаг salary_outlier_flag не используется для удаления записей.

Извлечение навыков

С помощью регулярных выражений алгоритм извлекает технические навыки из доступных текстовых полей. В историческом наборе используются названия должностей и категории ролей. Обнаруженный термин показывает связь записи с навыком, но не подтверждает владение им участником опроса.

Расчет метрик

Для навыков с данными минимум за два года вычисляются SGR — изменение медианной зарплаты между первым и последним наблюдаемыми годами, DV — отношение числа записей между этими годами, и комплексный индекс DI. В зарплатном опросе DV отражает изменение числа записей с обнаруженным навыком. На результат влияют размер и состав выборки по годам. Российская вкладка использует текущие вакансии hh.ru и исторические индексы навыков для справочной оценки.

Классификация и визуализация

Навыки автоматически распределяются по четырем категориям: растущие, стабильные, угасающие и устаревшие. Результаты выводятся в интерактивный веб-дашборд, где пользователь может фильтровать данные, просматривать графики динамики зарплат и детальные таблицы рейтингов.

Используемые технологии

Программирование: Python — основной язык программирования. Pandas и NumPy — библиотеки для обработки и анализа табличных данных.
Обработка текста: Регулярные выражения (Regex) для парсинга и классификации навыков.
Визуализация и интерфейс: Streamlit — фреймворк для создания веб-дашборда. Plotly — библиотека для построения интерактивных графиков.
Хранение данных: Формат CSV для исходного датасета и файлов с результатами анализа.
Разработка и тестирование: PyCharm или VS Code — среды разработки. Git и GitHub — для контроля версий и хранения кода. Ручное тестирование пайплайна обработки данных для поиска логических ошибок.


Локальная конфигурация hh.ru

Скопируйте `config.example.py` в `config.py` и укажите локальные значения.
Для текущего клиента используются `HH_ACCESS_TOKEN` и `USER_AGENT_EMAIL`.
Переменные окружения с этими именами имеют приоритет над локальным файлом.
Без токена клиент не отправляет заголовок Authorization; доступность поиска
без авторизации зависит от правил API hh.ru. Client ID и Client Secret
текущим поисковым клиентом не используются.
Проверено в существующем окружении Windows с Python 3.14.4. Для закреплённых зависимостей нужен Python не ниже 3.12.
Активация окружения не обязательна. В PyCharm выберите интерпретатор `.venv\Scripts\python.exe`. Если `python` не найден, используйте полный путь к установленному python.exe.

Для поиска вакансий требуется интернет; настройка авторизации описана выше. Файлы `.env` автоматически не загружаются: используйте переменные окружения или `config.py`.
